# Global Superstore Sales Dashboard

## Project Overview
This project analyzes Global Superstore sales and profit data using Microsoft Excel. It presents business performance through PivotTables, charts, and a dashboard.

## Objectives
- Analyze total sales and profit.
- Compare sales across different markets and regions.
- Understand sales and profit by product category.
- Summarize key business metrics in one dashboard.

## Tools Used
- Microsoft Excel
- PivotTables
- Charts
- Excel formulas
- Data analysis and visualization

## Key Analysis
- Total Sales
- Total Profit
- Sales by Market
- Sales by Category
- Profit by Category
- Sales by Region

## Dashboard
The dashboard provides a visual summary of sales and profit performance to help users compare markets, regions, and product categories.

## Skills Demonstrated
- Data analysis
- Data summarization
- Data visualization
- Dashboard creation
- Business insights
